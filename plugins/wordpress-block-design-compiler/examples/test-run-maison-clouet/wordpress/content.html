made to order / behind the counter

Candles and sprays poured slowly, never pretending to be antiques.

Each scent starts with a place note: cold stone at 8 a.m., tomato leaves under a basket, waxed church wood, rain on old paper. I blend in tiny batches so the scent shelf feels alive.
